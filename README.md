# Weather Prediction MLOps Project

Ce projet personnel met en œuvre un pipeline d'Intégration Continue pour le Machine Learning (**MLOps**) appliqué à la prédiction météo.

## 🚀 Fonctionnalités du pipeline CI
- Analyse et prétraitement automatique du jeu de données (`preprocess_dataset.py`).
- Entraînement automatique d'un modèle de classification (`train.py`).
- Génération et publication automatique d'un rapport de performance (**CML**) directement dans les Pull Requests.

## 🛠️ Outils utilisés
- **GitHub Actions** pour l'orchestration CI.
- **CML (Continuous Machine Learning)** pour les rapports d'évaluation visuels.
- **Scikit-Learn** & **Pandas** pour la partie modélisation Python.
